# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of WinVora.

| Version | Supported |
| --- | --- |
| 0.8.4 | Yes |
| Older versions | No |

Please update to the latest release before reporting a security problem.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through a public GitHub issue.

Send a private email to [winvoraadmin@gmail.com](mailto:winvoraadmin@gmail.com)
with the affected WinVora and Windows versions, a clear description, steps to
reproduce the problem, and relevant screenshots or log excerpts.

Remove usernames, serial numbers, local paths, IP addresses, and other personal
information before sending screenshots or logs. Please allow time to investigate
the report before sharing vulnerability details publicly.
